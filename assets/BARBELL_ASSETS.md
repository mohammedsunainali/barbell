# Barbell identity assets

`assets/barbell/` contains the BARBELL Design System V1 identity files supplied for this rebrand: icon-only, horizontal lockup and outlined wordmark. They are independently supplied brand assets and are distinct from the inherited openGym code and from third-party exercise media. The source archive is `BARBELL-DESIGN-SYSTEM-V1-OFFICIAL-FINAL.zip` (2026-09-24). Attribution and use rights for any supplied design artwork should be verified before external distribution.

The application source remains under the repository's GNU AGPL license and `NOTICE.md`. Exercise images and animations are not included in this identity asset directory; review `NOTICE.md` for their separate terms.
