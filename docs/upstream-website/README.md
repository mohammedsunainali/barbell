# Historical upstream website reference

These are the original openGym Docs, API, About, site script, original stylesheet, image builder and sitemap as inherited during the Barbell migration. Their release links, analytics, domains, screenshots and deployment assumptions describe the upstream site. They are retained as historical documentation and must not be deployed as Barbell pages without a separate rights, content and domain review.

Current Barbell website source is in `website/`. The actual API specification remains `api/openapi.yaml`; detailed technical guides remain under `docs/`.
